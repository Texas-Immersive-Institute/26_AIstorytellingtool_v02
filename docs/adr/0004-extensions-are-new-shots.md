# Extensions are new shots, played from where the new part starts

Extending a take creates a continuation shot right after its source shot instead of a new take in the same shot. The pack's low-res extend returns the source plus the new part already stitched, while extend + upscale returns only the new part, and we chose not to join files. So the low-res preview take is played from the point where the new part begins (an in-point, no re-encode), and the upscaled take, which is the new part only, plays whole. Either way the sequence shows the source shot and its continuation once each. The cost: Takes must remember each preview take's in-point, and it must make a 24 fps copy with ffmpeg when the source is an upscaled 48 fps take. Not yet verified: whether the upscaled extension matches the low-res preview when given the same seed.
